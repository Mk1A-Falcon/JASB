# JASB
JASB or Just Another Slackbot, an AI workflow by me for my online program #back-to-basics :)  
![TIME](https://hackatime.hackclub.com/api/v1/badge/U0AE3R4FR3R/JASB)

Currently, the bot only has 4 commands which do not utilize AI's in any form, though I will be working on them asap-
1. /jasb-ping : Pings the bot for it's latency.
2. /jasb-joke : Fetches a Joke.
3. /jasb-user_info : Fetches all availaible user information from the slack's "client" attribute.
4. /jasb-help : The help command for JASB slackbot

## To run it locally-
 + Navigate to the directory in which you want to host it and run-  
 "git clone https://github.com/Mk1A-Falcon/Baguette.git"
+ Run npm install to check for updates in dependencies.
+ Follow and input the api Keys accordingly in a seperate .env file as referred to as in the .env.example file.
